Калькулятор диапазонов IPv4-адресов

Классы A / B / C / D / E, пересчёт «маска ⇄ диапазон» и разбивка произвольного диапазона на блоки CIDR

Справочная таблица классов сетей

Классическая (classful) схема адресации — сейчас используется только как ориентир, реальные сети строятся по CIDR / VLSM

① IP-адрес + маска → диапазон

Введите IP-адрес и маску (в виде 255.255.255.0 или CIDR /24) — калькулятор посчитает сеть, широковещательный адрес и диапазон хостов

/

② Диапазон IP → маска / CIDR

Введите начальный и конечный адрес диапазона. Если диапазон точно соответствует блоку CIDR — покажется одна маска. Если не соответствует — диапазон будет разбит на минимальный набор блоков CIDR, которые в сумме дают этот диапазон.

–
Все вычисления выполняются локально в браузере, ничего не отправляется на сервер
