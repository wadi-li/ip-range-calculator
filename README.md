# Калькулятор диапазонов IPv4-адресов

Автономный HTML-калькулятор для сетей классов A, B, C (а также D/E) с пересчётом маски в диапазон и обратно. Работает полностью локально в браузере, без зависимостей и без интернета.

## Возможности

- Справочная таблица классов A/B/C/D/E, loopback и приватных диапазонов RFC 1918
- **IP + маска → диапазон**: маска в формате `255.255.255.0` или `/24`; адрес сети, broadcast, диапазон хостов, wildcard, бинарная маска, класс адреса; корректная обработка `/31` и `/32`
- **Диапазон IP → маска/CIDR**: точный CIDR, если диапазон в него укладывается, иначе — минимальный набор CIDR-блоков и наименьший общий supernet
- Кнопка «Копировать результаты» в каждом блоке (текстом), клик по отдельному значению или CIDR-блоку копирует только его
- Светлая тема по умолчанию, переключатель на тёмную (выбор сохраняется)

## Использование

Откройте `index.html` в любом браузере или воспользуйтесь онлайн-версией на GitHub Pages.
